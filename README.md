# Kailas P K - Portfolio Website

A modern, responsive personal portfolio website for Kailas P K, a Backend Software Engineer with 5+ years of experience.

## 🚀 Features

- **Modern Design**: Clean, professional layout with beautiful gradient backgrounds
- **Responsive**: Fully responsive design that works on all devices
- **Dark/Light Mode**: Toggle between dark and light themes
- **Smooth Animations**: Framer Motion animations throughout the site
- **Performance Optimized**: Built with Next.js 14+ for optimal performance
- **SEO Optimized**: Comprehensive meta tags and Open Graph support
- **Accessibility**: Following a11y best practices

## 🛠️ Tech Stack

- **Framework**: Next.js 14+ with App Router
- **Language**: TypeScript
- **Styling**: TailwindCSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Ready for Vercel deployment

8. **Languages**: Multilingual communication abilities
9. **Footer**: Contact details and social links

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd kailas-portfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Building for Production

```bash
npm run build
npm start
```

## 🎨 Customization

### Personal Information

Update the content in each section component to reflect your personal information:

- Contact details in `Hero.tsx` and `Footer.tsx`
- Professional experience in `Experience.tsx`
- Skills and technologies in `Skills.tsx`
- Project details in `Projects.tsx`
- Education history in `Education.tsx`
- Certifications in `Certifications.tsx`

### Styling

- Colors and gradients can be modified in the component files
- Global styles are in `globals.css`
- Tailwind configuration can be updated in `tailwind.config.js`

### Resume

Replace `/public/resume-placeholder.md` with your actual PDF resume named `resume-kailas-pk.pdf`
